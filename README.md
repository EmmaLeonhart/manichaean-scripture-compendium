# Manichaean Scripture Compendium

An open compendium of Manichaean scripture: the surviving texts of Mani's
religion in Coptic, Greek, Middle Persian, Parthian, Sogdian, Old Uyghur and
Chinese, gathered in one place in English.

- **License:** the compendium's own content (introductions, notes and new
  translations) is released under [CC BY 4.0](LICENSE). Older translations
  reproduced here are in the public domain, and each one is marked with its
  status.
- **Hosting:** https://manichaeism.order.life (GitHub Pages from this
  repository).
- **Translations:** where no free translation exists, the text is translated
  afresh from the original language. Modern copyrighted translations are
  consulted as reference only and are never copied.

## Layout

- `research/`: the corpus survey, the copyright status of each source, and
  working notes (`research/SUMMARY.md` is the place to start).
- `data_lake/`: source material. `data_lake/downloads/` holds what the agent
  fetched.
- `queue.md` and `devlog.md`: the work queue and its log.
