# Queue

Work top to bottom, the first item only. Delete an item when it is done and
log it in `devlog.md`.

1. **Corpus inventory.** In `research/notes/corpus.md`, list every surviving
   Manichaean scriptural and liturgical text: language, manuscript(s),
   standard edition, existing English translations, and how complete it is.
   Cite each entry in `research/sources.md`.
2. **Copyright audit of older translations.** In `research/notes/copyright.md`,
   give the public-domain status in the US and EU of each candidate older
   translation (for example Le Coq 1911 Xwastwanift, Chavannes and Pelliot
   1911–13, Allberry 1938 Psalm-Book, Tsui Chi 1943 Hymnscroll, F.W.K. Müller
   1904). Give the translator's death date and the publication facts for each.
3. **Site skeleton.** Build a static GitHub Pages site (plain HTML/CSS,
   generated from Markdown by a small committed script). Add a CNAME of
   `manichaeism.order.life`, a home page, a page listing the texts, and a
   template for a single text page (introduction, source and license notice,
   then the text with section numbers). Turn Pages on.
4. **First text online.** Take the highest-value text from the audit that is
   public domain or the easiest to translate fresh, and publish it.
5. **Translation plan.** For each text that needs a fresh translation, record
   the base edition to translate from, its accessibility, and its copyright
   concerns (scholarly-edition rights).
